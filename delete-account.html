Chapaqay: ma'lumotlarni o'chirish

Ilovada ro'yxatdan o'tish yo'q — har bir o'rnatish tasodifiy anonim identifikator oladi. Shu identifikatorga bog'liq barcha ma'lumotlarni ikki usulda o'chirish mumkin.

1-usul. Ilova ichida (tavsiya etiladi)

  1. Ilovani oching → Yana → Sozlamalar.
  2. Ma'lumotlarimni o'chirish tugmasini bosing va tasdiqlang.

Darhol o'chiriladi: o'rnatish yozuvi (identifikator, rol, hudud), test va baholash natijalari, mutaxassis bilan yozishma, bulutdagi kundalik, xabarnoma tokeni, shuningdek qurilmadagi barcha ma'lumotlar. Foydalanish statistikasi serverda faqat barcha foydalanuvchilar bo'yicha umumiy kunlik sonlar ko'rinishida saqlanadi va sizga bog'lanmagan.

2-usul. Ilova o'chirib yuborilgan bo'lsa

abduazizrashidov6972@gmail.com manziliga "Ma'lumotlarni o'chirish" mavzusida xat yuboring. Imkon bo'lsa, ilovaning Sozlamalar → Ilova haqida bo'limida ko'rsatilgan anonim IDni yozing. ID ma'lum bo'lmasa, 24 oy davomida ochilmagan o'rnatish yozuvlari avtomatik o'chiriladi (shunda test natijalari hech kimga bog'lab bo'lmaydigan ko'rinishda qoladi).

Nima saqlanib qoladi

O'chirilgandan keyin sizga bog'lanadigan hech qanday ma'lumot saqlanmaydi. Avval hisoblangan umumlashtirilgan (shaxsga bog'lanmaydigan) statistik ko'rsatkichlar ilmiy nashrlarda qolishi mumkin.

Chapaqay: deleting your data

The app has no sign-up — each installation gets a random anonymous identifier. You can delete all data linked to it in two ways.

Option 1. In the app (recommended)

Open the app → More → Settings → Delete my data and confirm. This immediately deletes the installation record (identifier, role, region), questionnaire and assessment results, conversations with the specialist, the cloud copy of the diary, the notification token, and all data on the device.

Option 2. If the app is already uninstalled

E-mail abduazizrashidov6972@gmail.com with the subject "Data deletion". If possible include the anonymous ID shown in Settings → About the app. Installation records that are not opened for 24 months are deleted automatically (their questionnaire results then remain only in a form that cannot be linked to anyone). Usage statistics are stored only as daily totals across all users and are not linked to you.

What is retained

Nothing that can be linked to you. Previously computed aggregated (non-identifiable) statistics may remain in academic publications.
